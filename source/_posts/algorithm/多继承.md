## 算法内容

本文件演示 C++ 多继承和纯虚函数实现。

`A` 和 `B` 都是包含纯虚函数的抽象基类，`C` 同时继承二者，并分别实现 `afun` 和 `bfun`。`main` 创建 `C` 的对象后调用两个接口，输出对应返回值。这个例子用于观察一个派生类如何同时满足多个抽象接口，以及多继承下虚函数调用的基本形式。

## 算法实现

```c++
class A {
    public:
    virtual int afun() = 0;
};

class B {
    public:
    virtual int bfun() = 0;
};

class C : public A, public B {
    public:
    virtual int afun() {
        return 0;
    }
    virtual int bfun() {
        return 1;
    }

};

#include<iostream>
using namespace std;

int main() {
    C c;
    int a = c.afun();
    int b = c.bfun();

    cout << a << b << endl;
    return 0;
}
```
