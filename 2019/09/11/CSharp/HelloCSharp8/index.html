可空bool?类型

可空bool?类型可取的值有true，false，null，其运算符有&、|，逻辑与和逻辑或

true、false和null的运算关系

x y x & y x | y
true null null true
false null false null
null true null true
null false false null
null null null null

  • 以上的运算关系与SQL中的算法一致
